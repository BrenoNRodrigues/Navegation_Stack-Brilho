# Brilhante

## Informações do projeto

- **Aluno:** Breno Rodrigus
- **Aplicação:** Brilhante
- **Descrição:** protótipo mobile institucional sobre sustentabilidade, com
  login demonstrativo e telas de início, sobre e contato.
- **Tecnologias:** Expo, React Native, JavaScript e React Navigation.

## Como executar

1. Instale o Node.js e o npm.
2. Na pasta do projeto, instale as dependências:

   npm install
   

3. Inicie o Expo Web:

   
   npm run web

## Funcionalidades

- Login inicial com validação de campos obrigatórios e credenciais.
- Navegação para Home após login válido.
- Acesso às telas Sobre e Contato a partir da Home.
- Toolbar com título por tela e retorno à tela anterior.
- Informações institucionais, canais de contato e horário de atendimento.
